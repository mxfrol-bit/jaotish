# Matrix Engine

Закрытая AI-система системного профайлинга. Не гадание: числа и арканы считаются
детерминированным кодом, AI лишь собирает единый портрет поверх рассчитанных данных
и честно отмечает, какие методики ещё не подключены.

Стек: **FastAPI + Supabase + python-telegram-bot** (бот и API в одном процессе),
AI-синтез через **OpenRouter**, деплой на **Railway** из GitHub.

## Что считается в v0.1

| Модуль | Статус | Источник |
|---|---|---|
| Нумерология (пифагорейская) | ✅ calculated | свой код |
| 22 аркана (центральный крест) | ✅ calculated | свой код, формулы в `config/arcana.json` |
| Западная астрология / Джйотиш / Ба Цзы | ⛔ not_connected | подключаются в v0.2–0.3 |

**Кардинальное правило:** AI интерпретирует только поля со статусом `calculated`.
Нет модуля — поле получает статус, а не выдуманное значение.

## Структура

```
app/
  main.py            FastAPI + запуск Telegram-бота (polling) в lifespan
  config.py          переменные окружения
  models.py          схема профиля + enum calculation_status
  calc/matrix_calc.py детерминированный расчёт (нумерология + 22 аркана)
  synthesis.py       AI-синтез через OpenRouter (только calculated-поля)
  engine.py          сборка профиля end-to-end
  database.py        Supabase (хранение профилей и обратной связи)
  bot.py             Telegram-бот (диалог сбора данных)
  routers/profiles.py HTTP API + _ver / _diag
config/              формулы и таблицы (нумерология, арканы) — без правки кода
supabase/schema.sql  таблицы me_profiles, me_feedback
```

## Локальный запуск

Главная страница — `app/landing.html`, форма — `app/static/site.js`.
Основная сетка — `app/static/site.css`, внутренние страницы — `app/static/pages.css`.
Актуальная монохромная тема «Личный след» — `app/static/signal.css`.

Первый экран и выбор тем объединены одной WebGL-поверхностью из частиц:
`app/static/signal.js` управляет камерой, реакцией на курсор и переходами между
четырьмя формами. Геометрия — `app/static/signal-geometry.mjs`. Движение работает
только в видимой части страницы и останавливается кнопкой, при скрытии вкладки
или системном `prefers-reduced-motion`. Пауза сохраняет текущий кадр и запоминается
на устройстве. После потери WebGL-контекста показывается SVG, при восстановлении
ресурсы создаются заново. На телефоне число частиц и DPR ограничены.
Нативная прокрутка сохраняется, внешних библиотек для эффекта нет.

Без WebGL остаётся векторный `app/static/signal/trace.svg`. Он воспроизводится
из той же геометрии командой `node scripts/generate_signal.mjs`.
Локальные кириллические шрифты и их лицензии лежат в `app/static/signal/`.
Графика декоративная: расчёты и AI-разбор выполняются на сервере.

Предыдущая золотая серия сохранена в `app/static/particles/` как архив итерации;
актуальные страницы её не загружают. Сборка фронтенда не нужна.

В анкете можно выбрать готовый вопрос или написать свой (до 300 символов).
На сервер отправляется одно поле `main_request`; перед отправкой показан выбранный
текст. Форматирование даты поддерживает цифровую клавиатуру, вставку ISO-даты
и редактирование отдельных частей. Персональные данные формы на устройстве
не сохраняются. Меню телефона работает как нативный `details`, улучшения
клавиатуры и закрытия — в `app/static/navigation.js`.

Проверка даты, паузы и восстановления графики: `node --test tests/*.test.mjs`.
Проверка веб-формы без AI и внешней БД: `.venv/bin/python -m unittest discover -s tests -v`.
Для локального визуального прогона отключите `TELEGRAM_BOT_TOKEN`, чтобы не запускать
вторую копию polling-бота. Локальная страница без OpenRouter явно помечается
как превью и ссылается на рабочий сайт; форма не создаёт фиктивный AI-разбор.

Генерация через веб-формы перенаправляет на постоянный адрес `/r/{id}`.
Статус проверяется через `/r/{id}/status`; прерванный ответ провайдера считается
ошибкой. Основной разбор можно повторить с теми же данными. Задачи выполняются
в памяти одного процесса: перезапуск во время генерации прерывает задачу.
Завершённые результаты сохраняются в Supabase.

На странице результата доступны текстовый экспорт, печать в PDF, копирование ссылки,
явное сохранение ссылки в «Мои разборы» и уточняющий вопрос к AI.
Список ссылок хранится в localStorage только на текущем устройстве; это не аккаунт.
Уточнения опираются на готовый текст, не сохраняются и ограничены тремя запросами
за 10 минут на разбор, одновременно обрабатывается не больше трёх уточнений.
Лимиты действуют в одном процессе. Клиентский код — `app/static/reading.js`.

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполнить ключи; без них доступно только превью дизайна

# проверить расчётное ядро без зависимостей:
python -m app.calc.matrix_calc 1990-05-15 "Иван Иванов"

# поднять сервис:
uvicorn app.main:app --reload
```

## Переменные окружения

См. `.env.example`. Минимум для полного v0.1:
`OPENROUTER_API_KEY`, `SUPABASE_URL`, `SUPABASE_KEY`, `TELEGRAM_BOT_TOKEN`.

## Деплой (Railway)

1. Подключить GitHub-репозиторий к новому проекту Railway.
2. Задать env-переменные из `.env.example`.
3. Start command берётся из `railway.toml`.
4. Проверка прода: `GET /api/profiles/_ver` и `GET /api/profiles/_diag?token=<DIAG_TOKEN>`.
